# Roteiro 2 do Laboratório de Desenvolvimento de Aplicações Móveis e Distribuídas

Este repositório reúne uma série de implementações práticas para estudar comunicação entre clientes utilizando diferentes protocolos de rede. O foco da atividade é compreender o comportamento de TCP, UDP, multicast e WebSocket em cenários reais de rede.

A estrutura foi organizada em duas versões paralelas, em Java e Python, permitindo comparar a implementação e a lógica de cada linguagem em contextos equivalentes.

## Tecnologias

- Java 21
- Python 3
- Maven (para o projeto WebSocket em Java)
- Biblioteca `websockets` para Python
- Biblioteca `Java-WebSocket` para Java
